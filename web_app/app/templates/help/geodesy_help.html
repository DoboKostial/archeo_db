Import a CSV or TXT file containing one geodetic point per row. The expected column order is id_pts, x, y, h, code, notes. The point code and notes are optional. Coordinates must use the project SRID shown in the form.

Point codes

CodeMeaning
SUTracking boundaries of a stratigraphic unit
FXFix, for example a nail
EPExcavation polygon
FOPhotogrammetric point
NINivelation for making surfaces
PFPoint field for total station stationing
FIPoint for precise finds measuring
PRDirect profile measuring
SPSpecial meaning, described freely in notes

Supported delimiters are comma, semicolon and whitespace. A header row is optional. Empty lines and lines beginning with # or // are ignored.
