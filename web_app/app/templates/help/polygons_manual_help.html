This form creates/updates polygon metadata, with optional ranges of measured point IDs from tab_geopts. The geometry (geom_top/geom_bottom) is rebuilt only for supplied point ranges.

  • Polygon name: unique polygon identifier (primary key).
  • Parent polygon: optional, used for hierarchy.
  • Allocation reason: required, stored in tab_polygons.
  • TOP / BOTTOM point ranges: optional FROM–TO intervals (inclusive).

Tips

  • You can leave both sides empty, or define only TOP, only BOTTOM, or both.
  • Ranges may overlap; points are deduplicated by point ID during rebuild.
  • Points are connected in ascending ID order. Use Define geometry in the listing for a custom vertex order.
  • An omitted side keeps its existing geometry. Replacing manual/GIS edits requires explicit confirmation.
  • If geometry is not created, check that points exist in tab_geopts and form a valid polygon.
